# Module Map

| Module | Trách nhiệm | Không được làm |
|---|---|---|
| Identity | User, device identity, session, pairing | Điều khiển thiết bị |
| Assistant | Interaction, context, intent, response | Truy cập OS trực tiếp |
| Policy | Permission, risk, confirmation | Thực thi action |
| Actions | Action plan/task orchestration | Tự cấp quyền |
| Memory | Working/local/cloud/routine memory | Tạo authority |
| Routines | Definition, approval, execution | Tự mở rộng scope |
| Devices | Device node, capability, heartbeat | Chứa business rule AI |
| Integrations | External adapters | Quyết định policy |
| Audit | Append-only activity and security records | Sửa record đã sealed |
| AI Routing | Chọn local/cloud provider | Thực thi side effect |
