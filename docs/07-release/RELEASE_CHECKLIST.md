# Release Checklist

## Before release

- [ ] Scope phiên bản đã đóng băng.
- [ ] Must-have tasks DONE.
- [ ] Build, unit, integration, architecture tests pass.
- [ ] Security review hoàn tất.
- [ ] Migration được test và có rollback.
- [ ] Installer/update flow được test.
- [ ] Changelog hoàn chỉnh.
- [ ] Known issues được công bố.
- [ ] Backup/recovery được kiểm tra.

## After release

- [ ] Smoke test production.
- [ ] Metrics/log không có bất thường.
- [ ] Rollback window được theo dõi.
- [ ] Release evidence được lưu.
- [ ] Retrospective và next milestone được cập nhật.
