Tạo một repository có khả năng được nhiều AI agent và developer tiếp tục an toàn, với source of truth, dependency protection, task tracking, quality gates và handoff rõ ràng.

## In scope

- Repository management structure.
- Solution/project skeleton.
- Dependency references.
- Architecture tests.
- CI foundation.
- Coding standards và quality gates.

- Wake word implementation.
- Browser automation.
- Cloud sync.
- Home Assistant behavior.
- Production deployment.

## Exit criteria

- Solution build thành công.
- Architecture tests bảo vệ dependency chính.
- CI chạy build và test.
- Task workflow và AI handoff hoạt động.
- Không còn blocker Critical.
